# Migration Module

## Purpose

Migration owns coordination and evidence for movement from inherited Tunarr
behavior to ChannelForge-owned implementations.

## Public Interface

Migration exposes migration status and compatibility usage through public
application contracts.

## Compatibility

Concrete inherited implementation remains under the Tunarr compatibility
boundary.

## Persistence

No schema or data migration is executed by this M02 shell.
